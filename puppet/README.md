# 人形劇をいじると台本ができるエディタ（3D）

舞台の上の人形・照明バトン・スピーカーを触ると、そのまま台本に演出が書き込まれる。
台本は1枚のまま。演出は触って入れ、人形劇でプレビューし、裏方・相方には従来形式の文字台本・キュー表として書き出す。

```bash
cd puppet
npm install
npm run dev          # 開発サーバー
npm test             # 単体テスト・スナップショット
npm run build:single # 1枚のHTML（dist-single/index.html）に固める
```

## 触り方

| 触るもの | 操作 | 台本に入るもの |
|---|---|---|
| 人形 | 左右にドラッグ | 移動（下手 <38・中央・上手 ≥62） |
| | 袖（両端9%）へ | ハケ |
| | 袖から舞台へ | 出 |
| | タップ | 入力欄の話者にする |
| 卵 | タップ | 話者を卵（『』）に |
| 吹き出し・（動き） | タップ | その場で書き換え |
| バトン | タップ／長押し | 明転・暗転／じわ（押した秒数 1〜8） |
| バトン端の ◎ | タップ | 灯体3つを個別のピンに（1回で戻る） |
| スピーカー | タップ／長押し | 新しい音源の C.I／F.I |
| ♪バッジ | タップ／長押し | その音源の C.O／F.O |

- 書き込み位置は台本で選択中の項目の直後（＝カーソルが今の場面）。
- 直前に書いたのと同じ対象をもう一度触ると上書き。元に戻ったら消える。
- 台本の記号チップはタップでミニ操作盤、長押しで掴んで別の行へ。

## 構成

- `src/model/` — UI から切り離した純粋関数（状態計算 `state.ts`、尺 `timing.ts`、編集 `edit.ts`、書き出し `export.ts`、ラベル配置 `layout.ts`）とテスト
- `src/store/` — undo/redo（`history.ts`）と IndexedDB 保存（`db.ts`）
- `src/ui/stage/` — three.js（React Three Fiber）の舞台。人形はプリミティブから組んだ3Dモデル（`Puppet3D.tsx`）
- `src/ui/` — 台本ビュー・チップ・入力欄・タイムバー・書き出し

役や小道具は `Doc.cast` で作品ごとに定義する（`kind: 'puppet' | 'prop'`、`look` で見た目）。

## 『父』のデータについて

参考プロトタイプ `chichi.html` がリポジトリに無かったため、`src/model/chichi.ts` は依頼書の書き出し例から再構成した抜粋。
`chichi.html` の台本データを JSON（`Doc` か `Item[]`）にして「渡す」→「⇧ 読み込む」で差し替えられる。
